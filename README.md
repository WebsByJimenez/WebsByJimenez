- 🤝 **Busco colaboraciones sin ánimo de lucro** y proyectos open source o de impacto social donde pueda aportar mi granito de arena y seguir aprendiendo en equipo.
- 🌱 Siempre curioseando nuevas herramientas y mejorando mi código cada día.
